# SafeSpace

SafeSpace is an Android emergency-support app prototype. The supplied Java source provides:
- Saving and removing emergency phone numbers locally with SharedPreferences.
- A tap-to-speak voice command flow that recognizes emergency keywords.
- A panic/SOS flow that prepares SMS messages for saved contacts and includes a Google Maps link when a location fix is obtained.
- Audio recording through a foreground microphone service, with recordings stored in the app's private files directory.
- A saved-recordings screen for playback and deletion.
- A dialer shortcut for India's 112 emergency number.

## Source layout

```text
app/src/main/
├── AndroidManifest.xml
└── java/com/example/safespace/
    ├── MainActivity.java
    ├── BackgroundAudioRecordService.java
    └── RecordingsActivity.java
```

## Build setup

This repository contains the recovered/available source files, not a complete Android Studio project. To build:
1. Open Android Studio and create a new **Empty Views Activity** project.
2. Set project name to `SafeSpace`, package to `com.example.safespace`, language to Java, and minimum SDK to API 26.
3. Keep the Gradle wrapper, project Gradle files, and theme files generated by Android Studio.
4. Copy the `app/src/main/` files in this repository into the matching location in the new project, replacing the generated manifest and adding the Java classes.
5. Ensure the app module uses `compileSdk` and `targetSdk` 35 or later.
6. Build and run on a physical Android phone. Grant permissions when prompted.

No `activity_main.xml` is required by this source version; the interface is created programmatically in Java.

## Important limitations and safety notes

- Voice activation is **tap-to-speak** using Android speech recognition followed by keyword matching. It is not always-on voice detection or a custom machine-learning model.
- SMS submission does not guarantee message delivery. Carrier charges may apply.
- Location is requested for a limited time; if unavailable, an SOS message can be submitted without a map link.
- Audio recordings are stored in the app's private local storage. This code does not encrypt recordings or upload them.
- This recovered source version does not implement importing contacts from the phone's address book, live tracking, or automatic cloud backup.
- Microphone recording must be started while the app is visible under modern Android foreground-service restrictions.
- Test only with consenting contacts and verify behavior safely. The panic action can send real SMS messages.
